# 1. Workflow-first 受控 Agent

[English](../../decisions/0001-workflow-first-controlled-agent.md) · **简体中文**

日期：2026-08-20

## 状态

已接受（Accepted）

## 背景

药企合规预检牵涉患者安全、个人信息、超适应症推广、商业红线、证据版本、专业审核与审计。**一次错误的 `allow` 不是一个糟糕的回答，而是一句本不该发出去、却已经发出去的表述。**

开放式多 Agent 设计让 Agent 自行决定步骤、工具与最终放行结论，等于把上述每一个后果都变成提示词的概率函数。这既难以验证、难以回放，也难以向那个必须签字的审核人解释清楚。

## 决策

控制流位于确定性编排器与状态机之中。最终路由由规则、权限、证据包、Schema 校验与人工审核控制。

模型的职责被限定在有界的语义工作：读懂中文叙述、结构化抽取、候选 finding 与证据解释。**它无法设置决定、严重度、路由、批准状态或工具权限。**

## 后果

- 高风险路径能够失效安全、移交人工，并可从不可变快照 id 回放。
- 新模型、新任务与新供应商通过模型网关与版本化策略接入，不改变最终合规门禁。
- 工程量高于一次简单的聊天调用，而且模型无法挽救规则判错的案例——误报需要修规则，而不是换一个更好的提示词。申诉通道与反馈闭环正是因为这个取舍而存在。
- 审核人的信任成为真正的约束条件，这也是监督必须双向度量、而不能假定成立的原因。
